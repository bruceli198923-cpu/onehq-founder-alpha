# OneHQ Founder Alpha Roadmap

## Phase 1 - GitHub Foundation

- Put Founder Alpha into a GitHub repository.
- Keep product philosophy, architecture and roadmap close to the code.
- Create issues for backend, AI orchestration, tool adapters and UX iterations.
- Use OneHQ itself as the first dogfood company.

## Phase 2 - Functional Application

- Move from static app to a real application framework.
- Add persistent database entities for Founder, Company, Employee, Project, Task, Deliverable, Brain, Tool and Audit.
- Add authentication.
- Add company boundary enforcement.
- Add employee creation, editing, retirement and performance review.

## Phase 3 - AI CEO Orchestration

- Connect CEO Command to a real orchestration backend.
- Implement intent parsing.
- Generate project plans, task contracts and deliverable contracts.
- Add review and rework loops.
- Store structured executive briefings.

## Phase 4 - Tool-Using AI Staff

- Implement Tool Registry as real capability infrastructure.
- Connect first tools:
  - GitHub for repo work, issues, pull requests and code history.
  - Codex for software engineering tasks.
  - OpenAI API for model routing.
  - Browser/research tools for market and product research.
  - Document generation for reports, memos and PRDs.
- Add per-tool audit logs.
- Add authority approvals before risky calls.

## Phase 5 - Deliverables as Core Object

- Make deliverables editable, reviewable and exportable.
- Support report, PRD, memo, decision, design and code deliverables.
- Link deliverables to project history, task contracts, reviewers and Founder decisions.

## Phase 6 - Company Brain

- Add file ingestion.
- Add voice and text training.
- Add employee-specific knowledge and SOP.
- Add decision and lesson extraction from completed work.

## Phase 7 - Production System

- Deploy hosted app.
- Add billing/cost tracking.
- Add secure secrets and tool credentials.
- Add workspace-level observability.
- Add backup and export.
